#  Task-4 CSS Unites, Box Models, Font

A responsive card component built strictly using HTML, CSS box model, and viewport units without modern layout systems or positioning hacks.

## Requirements Covered
* Main container sized and positioned using viewport units (`vw`, `vh`)
* 25% screen spacing on the left and right
* 10% screen spacing on the top and bottom
* Fits cleanly inside the viewport without page scrollbars
* Interactive anchor tag styled as a gradient button
* Built without Flexbox, "overflow: hidden", or relative/absolute positioning.

## Frontend 
* HTML5
* CSS3
